2. Start the flasher on the GBA

  1. With the GBA off, put the bootleg (repro) cart in the GBA and connect the link cable.
  2. Press Send flasher, then turn the GBA on while holding START + SELECT (this skips the cart and waits for the link cable).
  3. The GBA shows "Burn2Slot for GB-Link" and the flash chip is detected.

Back up / restore a save
